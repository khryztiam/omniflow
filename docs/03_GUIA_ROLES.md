# OmniFlow — Manual de uso por roles

Este manual reúne las funciones principales disponibles para administración,
supervisión y usuarios. Las acciones visibles pueden variar según el rol y los
permisos asignados a cada cuenta.

## Acceso

Ingresa con las credenciales asignadas para tu cuenta en la URL configurada
para el entorno. Después de iniciar sesión, OmniFlow abre el espacio de trabajo
correspondiente al rol:

| Rol | Inicio |
| --- | --- |
| Administración | `/admin/dashboard` |
| Supervisor | `/supervisor/dashboard` |
| Usuario | `/user/dashboard` |

## Administración

El rol de administración gestiona la operación general de OmniFlow:

- Consulta tareas, responsables, estados, fechas y estadísticas generales.
- Crea y edita tareas, y las asigna a sus responsables.
- Administra usuarios, ubicaciones y catálogos de estados y prioridades.
- Envía alertas a usuarios y consulta comentarios y evidencias de las tareas.

Usa los filtros y las vistas de seguimiento para identificar tareas atrasadas o
cargas que requieran atención. Confirma los datos de una tarea antes de editar
su asignación o estado.

## Supervisión

El rol de supervisor da seguimiento a las tareas y a las personas dentro del
alcance asignado:

- Consulta tareas propias y de usuarios supervisados.
- Filtra y revisa el avance, estado y fechas de las tareas.
- Crea o reasigna tareas dentro de su alcance cuando los permisos lo permiten.
- Consulta comentarios y evidencias, y gestiona las relaciones con usuarios
  supervisados.

Las tareas y los usuarios disponibles dependen del alcance configurado para la
cuenta; la supervisión no implica acceso global.

## Usuario

El rol de usuario trabaja con las tareas que tiene asignadas:

- Consulta sus tareas y su avance, estado y fechas.
- Actualiza el progreso y el estado de una tarea según las opciones disponibles.
- Agrega comentarios y carga evidencias relacionadas con el trabajo.
- Revisa las alertas recibidas y confirma su lectura cuando corresponda.

Mantén el avance actualizado y agrega comentarios cuando exista un bloqueo,
cambio relevante o información útil para quien da seguimiento.

## Flujo básico de una tarea

1. Abre la tarea desde la vista disponible para tu rol.
2. Revisa descripción, responsable, estado y fechas.
3. Actualiza el estado o progreso si tu rol tiene permiso para hacerlo.
4. Añade comentarios o evidencias que ayuden a documentar el trabajo.
5. Guarda los cambios y verifica que el detalle de la tarea muestre la
   información actualizada.

## Buenas prácticas

- Usa únicamente las credenciales asignadas a tu cuenta y no las compartas.
- Limita las acciones a las tareas y usuarios incluidos en tu alcance.
- No cargues evidencias que no estén relacionadas con el trabajo.
- Si una acción no está disponible, valida el rol y los permisos con
  administración.
